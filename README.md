# FitRed — แอพออกกำลังกายและโภชนาการส่วนบุคคล (PWA)

โปรเจกต์นี้คือ Progressive Web App (PWA) — เว็บแอพที่ผู้ใช้กด "เพิ่มลงหน้าจอโฮม" แล้วใช้งาน
เหมือนแอพมือถือทั่วไป มีไอคอน เปิดแบบเต็มจอ ใช้งานได้แม้ไม่มีเน็ต (หน้าที่เคยโหลดแล้ว)

## โครงสร้างไฟล์
```
fitness-pwa/
├── index.html          หน้าเว็บหลัก + meta tag สำหรับ PWA
├── public/
│   ├── manifest.json   ข้อมูลแอพ (ชื่อ, ไอคอน, สี) สำหรับตอนติดตั้งลงหน้าจอโฮม
│   ├── sw.js            service worker สำหรับ cache/ใช้งานออฟไลน์
│   ├── icon-192.png     ไอคอนแอพ
│   └── icon-512.png     ไอคอนแอพ (ขนาดใหญ่)
├── src/
│   ├── main.jsx         จุดเริ่มต้น ลงทะเบียน service worker
│   └── App.jsx          โค้ดแอพทั้งหมด (โปรไฟล์, แดชบอร์ด, โปรแกรม, สแกนอาหาร, แจ้งเตือน)
├── api/
│   └── analyze-food.js  serverless function ที่เรียก Claude API ฝั่งเซิร์ฟเวอร์ (ซ่อน API key)
└── package.json
```

## ขั้นตอนติดตั้งและรันในเครื่องตัวเอง
ต้องมี [Node.js](https://nodejs.org) ติดตั้งไว้ก่อน (เวอร์ชัน 18 ขึ้นไป)

```bash
cd fitness-pwa
npm install
npm run dev
```

จากนั้นเปิด `http://localhost:5173` ในเบราว์เซอร์

> หมายเหตุ: ฟีเจอร์ "สแกนอาหาร" จะยังใช้งานไม่ได้ตอนรันในเครื่อง เพราะ `/api/analyze-food`
> เป็น Vercel serverless function — ต้อง deploy ขึ้น Vercel ก่อนถึงจะเรียกใช้ได้ (ดูขั้นตอนด้านล่าง)
> หรือถ้าอยากทดสอบในเครื่อง ให้ใช้คำสั่ง `npx vercel dev` แทน `npm run dev`

## ขั้นตอน Deploy ขึ้นใช้งานจริง (แนะนำ: Vercel — ฟรี)

1. สร้างบัญชีที่ [vercel.com](https://vercel.com) (สมัครด้วย GitHub ได้เลย)
2. อัพโค้ดโฟลเดอร์นี้ขึ้น GitHub repository ใหม่
3. ที่หน้า Vercel กด **Add New → Project** แล้วเลือก repository นี้
4. ก่อนกด Deploy ให้ไปที่ **Settings → Environment Variables** เพิ่มตัวแปร:
   - `ANTHROPIC_API_KEY` = API key ของคุณ (ขอได้ที่ [console.anthropic.com](https://console.anthropic.com))
5. กด **Deploy** — รอ 1-2 นาที ก็จะได้ลิงก์ เช่น `https://your-app.vercel.app`

Vercel จะ build โปรเจกต์ Vite และรัน `api/analyze-food.js` เป็น serverless function ให้อัตโนมัติ
โดยไม่ต้องตั้งค่าอะไรเพิ่ม

## วิธีติดตั้งลงมือถือ (สำหรับผู้ใช้ทั่วไป)

**Android (Chrome):** เข้าลิงก์แอพ → แตะเมนู (จุดสามจุด) → "เพิ่มลงหน้าจอหลัก"

**iPhone (Safari):** เข้าลิงก์แอพ → แตะปุ่มแชร์ (สี่เหลี่ยมมีลูกศรขึ้น) → "เพิ่มไปยังหน้าจอโฮม"

หลังจากนั้นจะมีไอคอนแอพ FitRed อยู่ที่หน้าจอโฮม เปิดแล้วเต็มจอเหมือนแอพจริง

## ข้อจำกัดที่ควรรู้

- **การแจ้งเตือน**: ทำงานได้ก็ต่อเมื่อเปิดหน้าแอพ (หรือแท็บ) ค้างไว้ ถ้าปิดแอพสนิทหรือปิดเครื่อง
  จะไม่มีการแจ้งเตือน — เพราะ PWA ไม่มี background push แบบแอพ native เต็มรูปแบบ
  (บน iOS ข้อจำกัดนี้เข้มงวดกว่า Android)
- **ข้อมูลผู้ใช้**: บันทึกด้วย `localStorage` ในเบราว์เซอร์ของอุปกรณ์นั้นๆ ถ้าเปลี่ยนเครื่องหรือ
  ล้างข้อมูลเบราว์เซอร์ ข้อมูลจะหายไป (ถ้าต้องการ sync ข้ามอุปกรณ์ ต้องเพิ่มระบบบัญชีผู้ใช้ + ฐานข้อมูลจริง)
- **API key**: ห้ามใส่ ANTHROPIC_API_KEY ในโค้ดฝั่ง client เด็ดขาด เก็บไว้ที่ Environment Variable
  ของ Vercel เท่านั้น (ไฟล์ `api/analyze-food.js` ถูกออกแบบมาให้ทำงานแบบนี้อยู่แล้ว)

## ถ้าอยากได้แอพขึ้น App Store / Play Store จริง

โปรเจกต์นี้สามารถห่อด้วย [Capacitor](https://capacitorjs.com) เพื่อสร้างไฟล์ .apk / อัพขึ้น
App Store ได้ในภายหลัง โดยไม่ต้องเขียนโค้ด UI ใหม่ — บอกได้เลยถ้าอยากให้ช่วยขั้นตอนนี้ต่อ
